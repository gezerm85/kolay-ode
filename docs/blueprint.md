# **App Name**: Kolay Öde

## Core Features:

- Payment Configuration: Allow the business owner to specify the payment amount and installment options.
- Unique Link Generation: Generate a unique payment link based on the configured amount and installment options.
- Customer Payment View: Display the payment amount and installment options clearly to the customer on the payment page.
- Mobile-Friendly Payment Processing: Allow customers to make payments through the generated link.  It must function on mobile screens.
- Payment Tracking Dashboard: Provide a dashboard to track payment details, like dates, amounts, partial payments and status.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to evoke trust and security.
- Background color: Very light grayish-blue (#F0F4F9).
- Accent color: Vibrant orange (#FF9800) for calls to action.
- Body and headline font: 'Inter' (sans-serif) for a modern, clean, and easily readable interface.
- Use simple, line-based icons to represent different payment options and actions.
- Design a responsive layout that adapts seamlessly to various mobile screen sizes.
- Implement subtle animations for loading states and successful payment confirmations.
